# hirn documentation

hirn is a cognitive memory engine for AI agents — a database whose primitives are recall,
consolidation, and reasoning over time rather than rows and joins.

If you are new here, read these three in order:

1. **[Getting Started](@/docs/getting-started.md)** — install it and store your first memory.
2. **[Cognitive Model](@/docs/concepts/cognitive-model.md)** — the four layers and why they exist.
3. **[HirnQL Reference](@/docs/hirnql-reference.md)** — how to ask questions of the memory.

Everything else is reference material, organised below.
